# Setor: comunidade e leitores

Status: princípios definidos; interface não implementada.

No final de cada edição, área de sugestões e opiniões: assuntos desejados, avaliação da edição e comentários gerais. Baixa fricção e respeito à privacidade: coleta mínima de dados, proteção contra spam e moderação antes de tornar comentários públicos.

Sugestões fornecem hipóteses de pauta, não instruções para distorcer fatos. Quando apropriado, reconhecer contribuição dos leitores com autorização. Edições antigas continuam disponíveis. Sem criar comunidade artificial ou inflar métricas.
