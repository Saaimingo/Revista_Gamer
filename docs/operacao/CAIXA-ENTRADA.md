# Caixa de entrada dos blocos

**Quadro oficial de recados:** [GitHub Issues](https://github.com/Saaimingo/Revista_Gamer/issues).

Esta página explica o mecanismo; não é uma segunda lista manual a ser sincronizada. Abrir Issues para pedidos entre setores, dúvidas bloqueantes, propostas de mudança e defeitos. Usar o [protocolo de handoff](PROTOCOLO-HANDOFF.md) e o template do repositório.

Ao iniciar uma sessão, o bloco consulta as Issues abertas que mencionem seu setor, depois verifica o status dos arquivos da própria pasta. Se uma Issue tiver sido criada e nenhum bloco a consultou, **não há garantia de processamento**. Somente uma integração futura autorizada poderá fazer notificações e gatilhos automaticamente.
