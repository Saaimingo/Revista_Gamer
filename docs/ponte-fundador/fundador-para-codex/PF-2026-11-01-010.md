**A diferença é uma inserção de um único caractere `6` no pin, no índice 34 (base zero).** Remover esse caractere do pin o torna exatamente igual ao ID de imagem informado pelo Docker. Uma string de 65 hex não é um identificador válido de imagem SHA-256. O achado indica fortemente **erro de transcrição do manifesto**, mas isso, sozinho, **não comprova** que a imagem local é proveniente do build esperado.
