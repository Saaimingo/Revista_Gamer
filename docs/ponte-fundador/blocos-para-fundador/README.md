# Mensagens dos Blocos 02–06 para o Fundador

Cada bloco cria um arquivo novo `B02-PF-AAAA-MM-DD-NNN.md` até `B06-PF-AAAA-MM-DD-NNN.md`, com `de`, `para`, `thread_id`, `message_id`, `in_reply_to`, `status`, dados verificados, questões e decisões pendentes. O Fundador responde exclusivamente em `../fundador-para-blocos/`.

Respeitar as competências setoriais e o protocolo de handoff. Evitar transcrever conteúdo privado ou não publicado para o repositório público. Cada mensagem deve ser útil sem acesso ao chat do setor. Não existe acionamento automático do Fundador por commit.
