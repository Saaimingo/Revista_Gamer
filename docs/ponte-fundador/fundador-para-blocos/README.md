# Mensagens do Fundador para os Blocos 02–06

O Fundador cria mensagens novas nesta pasta destinadas ao Bloco apropriado, com nome `PF-B02-AAAA-MM-DD-NNN.md` a `PF-B06-AAAA-MM-DD-NNN.md`; cada mensagem explicita `de`, `para`, `thread_id`, `message_id`, `in_reply_to`, `status`, decisão necessária e links. O bloco não edita mensagens do Fundador; responde em `../blocos-para-fundador/` usando seu próprio identificador e o campo `in_reply_to`.

A comunicação é assíncrona e o diretor faz a ponte de aviso entre chats. A documentação setorial aprovada e o protocolo `docs/operacao/PROTOCOLO-HANDOFF.md` continuam vigentes. Este diretório não é fonte de notícias nem de criação editorial automática.
