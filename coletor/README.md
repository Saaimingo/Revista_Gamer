# Coletor — teste de captação da Revista Back

Esta pasta foi criada para testar a entrega de resultados de pesquisa do ChatGPT ao GitHub.

- Repositório: Saaimingo/Revista_Gamer
- Pasta: coletor/
- Objetivo: receber um arquivo por execução com descobertas sobre hardware, jogos e mods.
- Cada notícia deve incluir título, URL de origem, data quando disponível, breve descrição factual e status de acesso à fonte.
- O pesquisador não deve inventar links, escrever reportagens completas ou alterar outros arquivos.
- O teste só será considerado bem-sucedido quando um arquivo de resultado novo aparecer nesta pasta no GitHub.

Nenhuma automação está ativada por este arquivo. Não é parte da fábrica em produção.
